# Padrões de critérios de aceite

Um critério de aceite é verificável. O formato padrão deste aplicativo é dado, quando, então.

## Formato dado quando então

- Dado o contexto observável, quando a pessoa age, então o resultado é conferível.
- Cada critério vira um item CA1, CA2, CA3 no plano de testes.
- "Funciona melhor" não é critério. "O contraste do texto de confirmação atinge 4,5:1" é critério.
- Dado um celular com o checkout aberto, quando a pessoa toca uma vez em Pagar, então o pagamento inicia.
- Dado o pagamento em carregamento, quando chega um toque extra, então só uma doação é criada.

## Perímetro no critério

O critério não amplia o escopo. Se o perímetro diz que meios de pagamento não mudam, nenhum critério pede meio novo.

A revisão confere se cada critério de aceite aparece no plano e se o perímetro foi respeitado.
